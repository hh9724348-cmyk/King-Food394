# KING FOOD | كينغ فود

React + TypeScript + Vite. Arabic RTL, cart with localStorage, WhatsApp ordering.

## Commands
- `npm install`
- `npm run dev`
- `npm run build`  -> outputs to `dist/`
- `npm run preview`

## Deploy on Vercel
1. Push this project (source, without `node_modules` and `dist`) to GitHub.
2. In Vercel: Add New > Project > import the repo.
3. Framework preset: Vite. Build command `npm run build`. Output directory `dist`. Install command `npm install`.
4. Deploy. No extra config files are needed.
